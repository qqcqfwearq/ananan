## 上传到 Gitee Pages

1. 在 [gitee.com](https://gitee.com) 新建一个仓库
2. 将本文件夹内所有文件推送到仓库根目录
3. 进入仓库 → 服务 → Gitee Pages → 开启
4. 部署成功后获得链接：`https://你的用户名.gitee.io/仓库名`

## 上传到腾讯云 COS

1. 创建存储桶，权限设为**公有读**
2. 上传所有文件到根目录
3. 开启静态网站功能，设置索引文档为 `index.html`
4. 获得 COS 域名或绑定自定义域名

## 上传到阿里云 OSS

1. 创建 Bucket，权限设为**公共读**
2. 上传所有文件
3. 设置默认首页为 `index.html`
4. 获得 OSS 域名或绑定自定义域名
